# ItemFilter (物品過濾)

[![Minecraft](https://img.shields.io/badge/Minecraft-26.3-brightgreen.svg)](https://minecraft.net/)
[![Fabric](https://img.shields.io/badge/Fabric-Loader%200.19.5-blue.svg)](https://fabricmc.net/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

**ItemFilter** 是一款專為 Minecraft Fabric 26.3 設計的**純客戶端物品過濾與容器分類模組**。
玩家可以為不同的箱子或分類需求建立專屬設定檔，當容器開啟時自動或手動檢驗箱內物品，僅保留清單內允許的物品與數量，超出限制或不在清單中的雜物將會自動丟出至世界中（模擬玩家按 Q / Ctrl+Q 丟棄），完全無須更動伺服器端插件或架構！

---

## ✨ 核心特色

1. **純客戶端運作 (Client-Side Only)**
   - 不修改伺服器架構與世界資料，相容所有原版與各類型伺服器（Paper / Purpur / Fabric 等）。
   - 模擬玩家容器操作封包，多餘物品自然丟棄在玩家身前。

2. **完整容器支援 (Universal Container Support)**
   - 支援所有具備容器界面的方塊與實體：箱子、大箱子、界伏盒、木桶、漏斗、發射器、投擲器等。

3. **靈活多設定檔系統 (Profiles)**
   - 支援建立多個自訂名稱的設定檔（例如：「土希拉」、「礦物箱」、「農作物」）。
   - 啟用某個設定檔後持續生效，直到玩家切換或取消選取。

4. **容器左側控制面板 (Sidebar Widget)**
   - 開啟任何容器時，於容器界面左側空白處自動顯示四合一捷徑按鈕：
     - **設定檔切換鈕**：快速輪替目前啟用的設定檔，支援滑鼠中鍵一鍵鎖定/暫停過濾。
     - **🧹 過濾**：立即執行容器過濾並丟棄超額物品。
     - **📥 擷取**：一鍵將當前箱子內所有物品不重複導入目前設定檔。
     - **⚙️ 設定**：開啟詳細設定視窗。

5. **智慧數量與 NBT 保留規則**
   - **獨立數量上限**：每個物品可各自設定保留數量（如 64、128 或無上限）。
   - **統一批量套用**：可一鍵將統一數量套用並覆蓋至目前設定檔內的所有物品。
   - **NBT / 資料組件比對**：支援個別切換或統一設定「嚴格比對 NBT」或「純物品 ID 模糊比對」。

6. **便捷操作手感**
   - **滑鼠中鍵快速操作**：在容器或背包內滑鼠中鍵點擊物品，即可直接將該物品加入目前啟用設定檔。
   - **預設快捷鍵**：預設按下 `O` 鍵隨時開啟物品過濾設定視窗（可於按鍵設定中自訂）。

## 📥 安裝需求

- Minecraft **26.3**
- Fabric Loader **>= 0.19.5**
- Fabric API **0.161.0+26.3**
- Java **25**

## 🎮 使用指南

1. **基本過濾流程**
   - 走向任何箱子或容器並打開。
   - 若已有設定檔，點擊左側設定檔按鈕切換至目標設定檔（例如「土希拉」）。
   - 點擊「🧹 過濾」，系統將自動保留規則清單內的物品，其餘物品直接從箱子丟出。

2. **快速擷取箱子內容**
   - 將你希望保留的物品放入箱子中。
   - 點擊容器左側的「📥 擷取」按鈕，系統會將箱內所有物品自動整理不重複地寫入目前設定檔。

3. **管理與微調規則**
   - 點擊容器左側的「⚙️ 設定」或按下 `O` 鍵進入設定中心。
   - 可在左側新增、重新命名、刪除設定檔。
   - 在右側可獨立增減各物品數量、切換 NBT 比對、或使用上方「統一套用數量」一鍵取代。

## 📜 更新日誌 (Changelog)

### v1.0.5 (2026-10-11) - 提取防誤觸確認彈窗、物品詳細 NBT 預覽與設定檔鎖定防護
- **提取防誤觸二次確認介面 (`CaptureConfirmScreen`)**：點擊「📥 擷取」或滑鼠中鍵提取時，全面改為開啟獨立確認對話框，條列所有待加入物品，支援單項「✔ 加入」、「✕ 略過」與「✔ 全部確認加入」，徹底告別誤觸直接竄改設定檔。
- **懸浮物品詳細 Tooltip 與組件 NBT 預覽**：在確認介面中懸浮滑鼠於物品圖示或名稱上方，自動呈現原版標準 Tooltip（名稱、屬性）並額外附加格式化、著色與分行折疊之 DataComponents / NBT 組件詳情。
- **個別設定檔防修改鎖定機制 (`Profile Lock`)**：
  - 在設定介面（`ItemFilterScreen`）左側操作區提供「🔒 鎖定設定檔 / 🔓 設定檔未鎖定」切換開關。
  - 鎖定中的設定檔在列表前綴呈現 `§6🔒` 標記，並在執行擷取或中鍵提取時自動攔截防護並提示，只有回到設定介面才能手動解鎖。

### v1.0.4 (2026-10-11) - 容器擷取 Key 格式統一、伺服器大廳菜單過濾增強與穩定性完善
- **容器擷取命名空間統一**：將從容器批量擷取物品時的暫存鍵值生成全面規範為標準註冊表 ID（`BuiltInRegistries.ITEM.getKey`），杜絕內部鍵與標準規則比對脫節的隱患。
- **大廳與導航菜單過濾擴充**：進一步加強多人伺服器虛擬容器防誤判機制，加入「大廳」等中文導航菜單辨識，防範登入與選服時的誤拋出。
- **資料組件（NBT）記憶體節約驗證**：強化 DataComponents 記憶體生命週期管理，關閉 NBT 比對時嚴格維持空字串，防止長字串造成記憶體膨脹與 GC 負擔。

### v1.0.3 (2026-10-11) - 介面互動極致流暢、防止伺服器選單誤判與執行緒安全增強
- **UI 原地局部更新（0ms 零凍結）**：全面移除調整數量（+1 / -1 / +64 / -64 / 64與無上限切換）與 NBT 比對開關時銷毀重建 50+ 組件的 `init()` 反模式，改採原地文字與狀態更新，徹底消滅 Micro-stutter 與掉幀。
- **側邊欄按鈕防重複堆疊洩漏**：`ItemFilterSidebar` 增加去重判定，防止玩家頻繁進出設定介面或視窗縮放 (Resize) 時在容器左側無限疊加按鈕。
- **防止伺服器選單誤判與封包擁塞**：`FilterExecutor` 智慧辨識伺服器常見選單與非實體容器（排除包含 menu / 選單 / 菜單 / server 標題及未就緒連線），徹底解決進伺服器時誤將選單當雜物整箱拋出所引發的防作弊處罰、連線擁塞與載入卡死。
- **修正精確拋出邏輯**：修正部分超額物品邏輯，僅發送精準數量之 `dropSingle` 封包，絕不誤呼叫 `dropStack` 拋出整組應保留的物品。
- **JSON 序列化執行緒安全快照**：非同步儲存與即時儲存於 `synchronized` 鎖下預先生成資料字串快照，杜絕背景執行緒與主遊戲執行緒併發修改引發的 `ConcurrentModificationException`；視窗關閉改為完全非同步保存，消除按 ESC 的瞬間磁碟 I/O 停頓。

### v1.0.2 (2026-10-11) - 存檔流暢度、記憶體優化與批量無上限增強
- **批量設定支援「全部無上限」**：GUI 批量工具列新增「全部無上限」一鍵按鈕，輸入框全面支援「無上限」與 `-1` 輸入與回顯；修正容器一鍵擷取時若設定檔為無上限會被誤判 fallback 的問題。
- **500ms 存檔防抖與原子寫入**：引入 Scheduled 防抖與暫存檔原子替換 (Atomic Write)，搭配 `BufferedWriter` 緩衝，根除高頻按鈕點擊時的磁碟 I/O 洪流與關閉 GUI 時的主執行緒凍結卡頓。
- **消除 OOM 崩潰 (-805306369)**：精簡資料組件 (DataComponentsPatch) 儲存機制，若未啟用 NBT 比對則不常駐龐大 Patch 字串，避免大量容器資料堆積與頻繁 `.toString()` 造成記憶體溢出與 GC Overhead 崩潰。

### v1.0.1 (2026-10-11) - 效能極致優化版本
- **重構物品丟棄機制**：徹底消除單顆物品按 Q 造成的封包風暴與掉落物實體堆積。超額物品智慧改用整組拋出與低頻率佇列，確保遊戲 FPS 穩定。
- **O(1) Map 比對快取**：在設定檔比對層導入暫存 Map 索引，完全消除重複遍歷、Registry 查詢與字串建立。
- **GUI 繪製快取優化**：預先快取分頁物品圖示與字串，徹底消滅每秒 120+ 次的短期物件生成與 GC 微凍結 (Micro-freeze)。
- **非同步磁碟存檔 (Async Save)**：設定寫入移至背景執行緒執行，關閉介面時自動同步落盤，消除主渲染執行緒硬碟 I/O 卡頓。
