# ItemFilter (物品過濾)

[![Minecraft](https://img.shields.io/badge/Minecraft-26.3-brightgreen.svg)](https://minecraft.net/)
[![Fabric](https://img.shields.io/badge/Fabric-Loader%200.19.5-blue.svg)](https://fabricmc.net/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

**ItemFilter** 是一款專為 Minecraft Fabric 26.3 設計的**純客戶端物品過濾與容器分類模組**。
玩家可以為不同的箱子或分類需求建立專屬設定檔，當容器開啟時自動或手動檢驗箱內物品，僅保留清單內允許的物品與數量，超出限制或不在清單中的雜物將會自動丟出至世界中（模擬玩家按 Q / Ctrl+Q 丟棄），完全無須更動伺服器端插件或架構！

---

## ✨ 核心特色

1. **純客戶端運作 (Client-Side Only)**
   - 不修改伺服器架構與世界資料，相容所有原版與各類型伺服器（Paper / Purpur / Fabric 等）。
   - 模擬玩家容器操作封包，多餘物品自然丟棄在玩家身前。

2. **完整容器支援 (Universal Container Support)**
   - 支援所有具備容器界面的方塊與實體：箱子、大箱子、界伏盒、木桶、漏斗、發射器、投擲器等。

3. **靈活多設定檔系統 (Profiles)**
   - 支援建立多個自訂名稱的設定檔（例如：「土希拉」、「礦物箱」、「農作物」）。
   - 啟用某個設定檔後持續生效，直到玩家切換或取消選取。

4. **容器左側控制面板 (Sidebar Widget)**
   - 開啟任何容器時，於容器界面左側空白處自動顯示四合一捷徑按鈕：
     - **設定檔切換鈕**：快速輪替目前啟用的設定檔，支援滑鼠中鍵一鍵鎖定/暫停過濾。
     - **🧹 過濾**：立即執行容器過濾並丟棄超額物品。
     - **📥 擷取**：一鍵將當前箱子內所有物品不重複導入目前設定檔。
     - **⚙️ 設定**：開啟詳細設定視窗。

5. **智慧數量與 NBT 保留規則**
   - **獨立數量上限**：每個物品可各自設定保留數量（如 64、128 或無上限）。
   - **統一批量套用**：可一鍵將統一數量套用並覆蓋至目前設定檔內的所有物品。
   - **NBT / 資料組件比對**：支援個別切換或統一設定「嚴格比對 NBT」或「純物品 ID 模糊比對」。

6. **便捷操作手感**
   - **滑鼠中鍵快速操作**：在容器或背包內滑鼠中鍵點擊物品，即可直接將該物品加入目前啟用設定檔。
   - **預設快捷鍵**：預設按下 `O` 鍵隨時開啟物品過濾設定視窗（可於按鍵設定中自訂）。

## 📥 安裝需求

- Minecraft **26.3**
- Fabric Loader **>= 0.19.5**
- Fabric API **0.161.0+26.3**
- Java **25**

---

## 🎮 使用指南

1. **基本過濾流程**
   - 走向任何箱子或容器並打開。
   - 若已有設定檔，點擊左側設定檔按鈕切換至目標設定檔（例如「土希拉」）。
   - 點擊「🧹 過濾」，系統將自動保留規則清單內的物品，其餘物品直接從箱子丟出。

2. **快速擷取箱子內容**
   - 將你希望保留的物品放入箱子中。
   - 點擊容器左側的「📥 擷取」按鈕，系統會將箱內所有物品自動整理不重複地寫入目前設定檔。

3. **管理與微調規則**
   - 點擊容器左側的「⚙️ 設定」或按下 `O` 鍵進入設定中心。
   - 可在左側新增、重新命名、刪除設定檔。
   - 在右側可獨立增減各物品數量、切換 NBT 比對、或使用上方「統一套用數量」一鍵取代。

## 📜 更新日誌 (Changelog)

### v1.0.1 (2026-10-11) - 效能極致優化版本
- **重構物品丟棄機制**：徹底消除單顆物品按 Q 造成的封包風暴與掉落物實體堆積。超額物品智慧改用整組拋出與低頻率佇列，確保遊戲 FPS 穩定。
- **O(1) Map 比對快取**：在設定檔比對層導入暫存 Map 索引，完全消除重複遍歷、Registry 查詢與字串建立。
- **GUI 繪製快取優化**：預先快取分頁物品圖示與字串，徹底消滅每秒 120+ 次的短期物件生成與 GC 微凍結 (Micro-freeze)。
- **非同步磁碟存檔 (Async Save)**：設定寫入移至背景執行緒執行，關閉介面時自動同步落盤，消除主渲染執行緒硬碟 I/O 卡頓。

### v1.0.0 (2026-10-11)
- 初始版本發布。
- 支援 Fabric 26.3 與 Java 25。
- 實作容器左側懸浮控制列（設定檔切換、手動過濾、箱子擷取、設定中心）。
- 實作多設定檔管理與 JSON 持久化。
- 實作個別與統一數量保留限制（支援無上限與自訂數量）。
- 實作 NBT / DataComponents 資料組件嚴格比對與純 ID 比對切換。
- 支援滑鼠中鍵快捷加入物品與鎖定過濾。
- 整合 ModMenu 與繁體中文 (zh_tw) / 英文 (en_us) 語系支援。
